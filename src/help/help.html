WebClip — how to capture

Save any page — even course players and infinite feeds — as a clean, self-contained PDF. Three ways to do it: pick the one that fits the page.

Three ways to capture — and when to use each

📄 Capture & Save PDF  The everyday button in the popup. Grabs the whole scrollable page in one click — top to bottom, inner panels and all — and saves it. Ideal for: articles, dashboards, receipts, chat threads, documentation — anything where everything you need is already on the page.

📄 Full page (automated + mark)  First captures the whole page automatically as a base, then lets you go back into the same page and mark the states a single scroll can’t reach — a collapsed accordion, a different tab. Each marked view is spliced into the base at its own place, in order. Ideal for: course players (SCORM / Rise), docs with accordions or tabbed panels — the full page plus the content hidden behind clicks.

🎯 Mark only  No automatic base — you mark sections by hand and they’re stacked into one PDF, in the order you mark them. The session persists across pages/lessons: keep marking as you move through a course, then press Done for one multi-page PDF. Ideal for: a custom cut of specific sections, when the automatic full-page capture doesn’t suit a page, or when you simply don’t need the whole page — only a few parts.

All three save a self-contained PDF on your device — nothing is uploaded. Full page and Mark only share the exact same marking tool (below); they differ only in whether a full-page base is captured first.

Marking a section — the 3 presses

  1. Arm it. Press m or click 🎯 Mark. The button flips to ✕ Cancel mark so you know marking is on.
  2. Aim & select. Move the cursor — a dashed outline follows the block under it. Click once (or press m) to lock the selection (it turns solid). Fine-tune with ↑ to grab a bigger block or ↓ for a smaller one.
  3. Capture. Press m a second time (or Enter, or click the selection). WebClip grabs the whole section — even the part below the fold — and the button returns to 🎯 Mark for the next one.

Changed your mind? Esc or the ✕ Cancel mark button leaves marking without capturing.

Worked example ① — an accordion

An accordion hides its content until you open it. WebClip captures what’s on the page, so the rule is simple: open it first, then mark it.

Worked example ② — tabs (use ↑ to grab the header)

A tab widget shows one panel at a time behind a row of tab buttons (the tab bar / header). To capture every tab correctly, each mark must include that header — otherwise every panel looks the same and WebClip can’t tell them apart or place them together.

The trick: select a tab’s panel, then press ↑ once (or a few times) so the selection grows to also wrap the tab bar. Then capture. Repeat for each tab.

  1. Mark a tab’s content. Arm marking (m), aim at the visible panel, click to select it.
  2. Grow to the header. Press ↑ until the outline wraps the tab bar (buttons) as well as the panel. ↓ shrinks back if you overshoot.
  3. Capture, then next tab. Press m / Enter. Switch to the next tab on the page and repeat. Do the default (first) tab too, the same way.

Because every tab of a widget is marked with its header, Full page recognises they belong together and stacks them at the widget’s place in the page — in the order you captured them.

The floating toolbar

Count shows how many sections you’ve captured. ↶ Undo drops the last one (after a wrong mark — the rest are safe). ✓ Done assembles everything into the PDF. ✕ cancels the whole session.

Split PDF — re-paginate a saved capture

A one-click Capture & Save (or a Full page capture) gives you Auto output: one continuous page that reads like the screen. When you want it on paper, use Split PDF (options page ⚙) to turn that saved capture into printable A4 or Letter pages — a clean PDF-to-PDF operation, no re-capture.

The breaks are content-aware: WebClip carries a whitespace map inside every capture it makes, so each page break lands in the gap between lines, paragraphs, or rows — it never slices through a line, a table row, or a coloured block.

Best results: split a capture made with the current version — the whitespace map is embedded at capture time. A PDF from another tool (or a very old WebClip build) has no map, so Split PDF falls back to fixed page heights that can cut a line; re-capture the page first for clean breaks.

Keyboard shortcuts

mStart marking; press again to capture the selected section.
EnterCapture the selected section.
↑ / ↓Grow / shrink the selection to get exactly the section you want.
EscCancel marking (nothing is captured).
Ctrl/⌘ + ZUndo the last capture.

Shortcuts use an English keyboard layout — switch layout if the keys don’t respond, or just use the toolbar buttons.

Tips

Which tool? If it’s all on the page, use Capture & Save. If content hides behind accordions or tabs, use Full page and mark those. If you only want specific parts (or across several lessons), use Mark only.

Accordions. Open the section first so its content shows, then mark it (see Worked example ① above). Marking grabs exactly the block you point at, so the sidebar and “Exit course” chrome stay out.

Tabs. Mark the panel, then press ↑ so the selection includes the tab bar too, and repeat for each tab (see Worked example ②). That’s what lets the tabs land together in the right place.

Across lessons. In Mark only, keep marking as you navigate to the next lesson — captures pile up and Done makes a single multi-page PDF.

Stamp. Turn on the stamp in Settings to add a title header and a footer (URL · capture time · page N/M) to every capture, including Full page + mark and Mark only.

While capturing, scrolling is locked so the page can’t shift mid-shot. That’s expected — it releases the moment the capture finishes.
